# SQL Testing

This section demonstrates how I use SQL as part of QA activities, including:

- Validating data in the database
- Setting up and cleaning test data
- Verifying API/UI behaviour against backend records
- Investigating defects using SQL queries

## Files

- `basic-queries.sql` – simple SELECT, WHERE, ORDER BY examples
- `joins-and-aggregations.sql` – INNER JOIN, LEFT JOIN, GROUP BY, HAVING
- `test-data-setup.sql` – INSERT, UPDATE, DELETE for test data
- `data-validation-queries.sql` – queries to validate business rules
- `bug-investigation-queries.sql` – queries used to reproduce or analyse defects

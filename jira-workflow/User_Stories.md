# User Stories

Below are sample user stories written in standard Agile format.

---

## User Story 1: Login Functionality
**ID:** US-001  
**As a** registered user  
**I want to** log into the application  
**So that** I can access my account

---

## User Story 2: Profile Update
**ID:** US-002  
**As a** logged-in user  
**I want to** update my profile information  
**So that** my account details remain accurate

---

## User Story 3: Password Reset
**ID:** US-003  
**As a** user who forgot my password  
**I want to** reset it using my email  
**So that** I can regain access to my account

---

## User Story 4: Login API Token Generation
**ID:** US-004  
**As a** system user  
**I want** the API to return a valid token  
**So that** I can authenticate securely

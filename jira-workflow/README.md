# 🗂️ Jira Workflow Simulation

This section simulates a complete Jira-style Agile workflow, covering the full manual testing lifecycle from requirements to reporting.  
It demonstrates how QA collaborates with developers, product owners, and the wider team in a real sprint environment.

---

## 📁 What’s Included

### **1️⃣ User Stories**
Business requirements written in a clear, testable format.

### **2️⃣ Acceptance Criteria**
Conditions that define when a user story is considered complete.

### **3️⃣ Test Scenarios**
High-level functional flows derived from acceptance criteria.

### **4️⃣ Test Cases**
Detailed step-by-step test cases with expected results.

### **5️⃣ Linked Test Cases**
Traceability matrix linking:
- User Stories  
- Acceptance Criteria  
- Test Scenarios  
- Test Cases  

### **6️⃣ Test Execution Report**
Execution results for the sprint, including pass/fail status and observations.

### **7️⃣ Defects**
Jira-style bug reports with:
- Severity  
- Priority  
- Environment  
- Steps to reproduce  
- Expected vs actual results  

### **8️⃣ Test Summary Report**
A final sprint-level summary covering:
- Coverage  
- Defect trends  
- Risks  
- Recommendations

---

## 📌 How to Navigate

If you're a reviewer:

1. Start with **User Stories** and **Acceptance Criteria**  
2. Move to **Test Scenarios** and **Test Cases**  
3. Review **Linked Test Cases** for traceability  
4. Check **Execution Report** and **Defects**  
5. Finish with the **Test Summary Report**  

This provides a complete view of the QA workflow from start to finish.

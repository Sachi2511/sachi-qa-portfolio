# Maven Project Structure

This section will describe the Maven folder structure and dependencies used in the framework.

## Standard Maven Layout:
src ├── main │    └── java ├── test │    └── java └── pom.xml

## What will be included here:
- Selenium Java dependency
- TestNG dependency
- WebDriverManager dependency
- ExtentReports dependency
- Build plugins

## Purpose of Maven:
Maven helps in:
- Managing dependencies
- Standardizing project structure
- Running tests via command line

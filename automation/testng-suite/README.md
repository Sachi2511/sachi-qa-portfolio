# TestNG Suite

This section will contain the TestNG configuration files and suite definitions.

## What will be included here:
- testng.xml file
- Parallel execution setup
- Grouping of tests (smoke, regression)
- BeforeSuite / AfterSuite configuration
- Retry logic (optional)
- Test listeners for reporting

## Purpose of TestNG Suite:
The suite file helps in:
- Controlling execution flow
- Running selected test groups
- Managing parallel execution


# ExtentReports

This section will contain the reporting setup for the automation framework.

## What will be included here:
- ExtentReports configuration file
- Report initialization in BaseTest
- Logging test steps
- Attaching screenshots on failure
- Generating HTML reports after execution

## Purpose of ExtentReports:
ExtentReports helps in:
- Creating visually rich HTML reports
- Tracking pass/fail/skip status
- Adding screenshots and logs

# Entry and Exit Criteria

Entry and Exit Criteria define when testing can begin and when it can be considered complete.

## 1. Entry Criteria
Testing will begin only when the following conditions are met:

- Requirements are clearly defined and approved
- Test environment is set up and stable
- Test data is prepared and available
- Test cases are reviewed and approved
- All necessary tools (Postman, Selenium, TestNG) are installed and configured
- Build is deployed to QA environment

## 2. Exit Criteria
Testing will be considered complete when the following conditions are met:

- All planned test cases are executed
- All high and medium severity defects are fixed and retested
- No critical/blocker defects remain open
- Regression testing is completed
- Test summary report is prepared
- Product Owner has reviewed and approved the test results

## 3. Notes
- Exit criteria may be adjusted based on project timelines
- Any deviation must be approved by the QA Lead and Product Owner
